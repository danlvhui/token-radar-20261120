How to farm it

    How the value is set. Implied value = TVL × 5% × a growth factor (0.75 at −50% seven-day change, 2.0 at +200%) × an age factor (1.0 when newly listed, 1.6 after four years with no token recorded). It uses only the snapshot's own figures — TVL, seven-day growth, and how long the protocol has run with no token recorded — never a hardcoded list of names. Protocols whose token already trades sit below the pre-token board; their implied value is their recorded market cap scaled by one common factor, and the unscaled figure is shown in the detail view.

    What “no token” means. The snapshot records no token for a protocol on the watchlist; that is not proof it has none, and it is not a promise that one will ever be issued. Farm steps are suggestions for using a protocol, not a guarantee of any reward.

    Data: DefiLlama protocol snapshot, frozen 14 November 2026. 758 protocols at or above $5M TVL; watchlist floor $50M.
